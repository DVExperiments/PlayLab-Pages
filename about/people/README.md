# Team photos

Photos uploaded here appear automatically in "Your educators and advisors" on the About page.

| Person | File name |
|---|---|
| Dr Claudio Aguayo | `claudio.jpg` |
| Dylan Verdonkschot | `dylan.jpg` |

- `.jpg`, `.jpeg`, `.png` and `.webp` all work (e.g. `dylan.png`). Use a lower-case ending.
- **Photo not showing?** Open its address directly, e.g. `https://YOUR-USERNAME.github.io/playlab-pages/about/people/dylan.jpeg`. If it downloads instead of showing, or shows a broken image, the file isn't a standard image inside (iPhone photos are often HEIC files with a .jpeg name). Open it in Preview, Photos, Paint or Canva, save or export it as PNG or JPG, upload it, and delete the old file.
- Use a portrait (taller than wide) head-and-shoulders photo, about 800 × 1000 pixels and under 400KB. Photos show in a 4:5 shape, cropped around the upper middle, so keep the face in the top half.
- To upload: open this folder on GitHub, click **Add file → Upload files**, drag the photo in, and click **Commit changes**. It appears on the page within a couple of minutes.
- To replace a photo, upload a new one with the same name. GitHub replaces the old file.
- To add a new person, see `SETTINGS → people` in `about/index.html`.
